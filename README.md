# Personal portfolio website

A responsive, static three-page portfolio built for GitHub Pages.

## Customize

Before publishing, replace these placeholders in the HTML files:

- The short biography and highlights on `index.html`

## Publish with GitHub Pages

1. Create a new GitHub repository and upload these files to its default branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the default branch and the `/ (root)` folder, then save.
5. GitHub will show the public site URL once the deployment finishes.

The site has no build process or dependencies; the HTML files can be hosted directly.
